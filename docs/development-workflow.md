# Development Workflow

EVE Trade v2 uses one active technical chantier at a time: one branch, one pull request, one phase issue.

Every working branch starts from current main.

A phase is complete only when implementation, relevant tests/type checks, integration validation and documentation are complete, the pull request is merged, and main is revalidated.

The issue tracker is an execution ledger, not a dumping ground. New observations belonging to the active phase are added to that phase issue unless independent tracking is required or explicitly requested.
